LOBO ANALYTICS & BUSINESS — SITE v3.4

Abra index.html em um navegador moderno. O pacote funciona localmente e pode ser publicado em hospedagem estática como GitHub Pages.

Estrutura baseada no layout editorial do material de referência enviado pelo usuário (Driezie), adaptada para as três ofertas e a identidade visual da Lobo.

Imagens: arquivos incluídos em assets/images; são demonstrações ilustrativas, não trabalhos realizados para clientes. A fotografia de notebook é imagem gerada para este projeto. Os outros visuais são mockups demonstrativos criados para a Lobo.

Navegação: index.html, servicos/, especialidades/, metodo/, sobre/, contato/ e páginas individuais das três ofertas.

Contato: mensagem preparatória e link do LinkedIn. Não há formulário com backend de envio nesta versão. Atualize a URL de contato para seu canal comercial antes de publicar.

Marca: símbolo oficial fornecido pelo fundador aplicado no cabeçalho e no favicon.

Preços internos não foram publicados.
