# Lobo Analytics & Business — Site institucional

## Publicação no Cloudflare Pages

1. Extraia o ZIP.
2. Envie **todo o conteúdo desta pasta** (não apenas o index.html) para a raiz do repositório GitHub do site.
3. Configure o Cloudflare Pages para servir o diretório raiz sem build (HTML estático).
4. Faça o deploy. A homepage é `index.html` e as quatro páginas estão em `servicos/`.

## O que foi incluído

- Homepage com 5 seções.
- 4 páginas individuais de soluções.
- Logos oficiais reutilizadas dos materiais da Lobo, sem redesenho.
- Layout responsivo, menu móvel, links funcionais para WhatsApp e e-mail.
- Diagramas ilustrativos identificados como exemplos.
